🤖 ESP32 Smart Surveillance Robot.      
📌 Project Overview

The ESP32 Smart Surveillance Robot is an IoT-based robotic system designed for wireless monitoring and surveillance. The robot can be controlled remotely and is capable of live monitoring using an ESP32 controller. 

🎯 Features

- Wireless Remote Control
- ESP32-Based System  
- Real-Time Surveillance
- Easy Navigation
- Low Cost and Efficient Design

🛠️ Components Used

- ESP32 Development Board
- Motor Driver
- DC Motors
- Robot Chassis with Wheels
- ESP32-CAM Module / Camera
- Battery
- Jumper Wires
- 
💻 Technologies Used

- ESP32
- Arduino IDE
- Embedded C/C++
- IoT
- Web Server / WiFi
- ESP32-CAM

⚙️ How It Works
1. ESP32 connects to WiFi and hosts a web server
2. User controls robot movement through web/mobile interface
3. ESP32-CAM streams live video for surveillance
4. Commands are sent wirelessly to move robot forward, backward, left, right
